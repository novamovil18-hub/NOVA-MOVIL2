# 📱 NOVAMÓVIL - Tienda Web Dinámica de Celulares

¡Bienvenido a **NOVAMÓVIL**! Una plataforma web de compra de smartphones moderna, dinámica, con colores vibrantes y neón de alto impacto visual, desarrollada con **HTML5, CSS3, JavaScript y JSON**.

---

## 🌟 Características Principales

1. **Contacto y Pedidos directos vía WhatsApp (`62644245`)**:
   - Botón en cabecera con pulso neón para contacto instantáneo.
   - Enlace en cada tarjeta de celular con mensaje personalizado que incluye el modelo y precio.
   - Botón de compra dentro de la ficha técnica detallada.
   - Carrito de compras que genera automáticamente la lista completa de pedidos y el total en Bs. para enviarlo al **62644245**.
   - Botón flotante siempre visible en la esquina inferior derecha.

2. **Personalización de Imágenes de Celulares**:
   - Botón **"📷 Cambiar Foto"** en cada modelo y dentro de la ficha técnica.
   - Permite subir fotos directamente desde la computadora (JPG, PNG, WebP) o pegar enlaces de internet.
   - Las fotos personalizadas se guardan automáticamente en el navegador (`localStorage`).

## 🚀 Cómo Abrir el Proyecto

### Opción 1: Directo en tu Navegador (Doble Clic)
Haz doble clic sobre el archivo [`index.html`](file:///c:/Users/HP/Desktop/NOVAMOVIL/index.html) para abrirlo en cualquier navegador.

### Opción 2: Con un Servidor Local
Abre una consola PowerShell dentro de la carpeta y ejecuta:
```powershell
python -m http.server 8080
```
Luego visita en tu navegador: [http://localhost:8080](http://localhost:8080)
